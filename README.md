# Zerodha

A full-stack Zerodha-inspired trading platform built using **React, Node.js, Express, and MongoDB**.

## 🚀 Features

- Trading dashboard
- Portfolio & holdings
- Orders and watchlist
- REST API with Express
- MongoDB database
- Responsive UI

## 🛠️ Tech Stack

**Frontend:** React.js, JavaScript, HTML, CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Deployment:** Vercel & Render

## 📁 Project Structure

```text
Zerodha/
├── frontend/     # Landing website
├── dashboard/    # Trading dashboard
├── backend/      # Express API
└── render.yaml
```

## ⚡ Run Locally

```bash
cd frontend && npm start
cd dashboard && PORT=3001 npm start
cd backend && npm run dev
```
